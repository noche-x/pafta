# Slop

These notes are AI-generated reverse engineering of the game's binaries (`subrosa.exe` and `editor.exe`), plus terrain reports from several AI models and an old UV investigation. They have not been checked properly.

Some of them contradict each other, and some contain guesses that were corrected later. Where the terrain notes disagree, [terrain_generation.md](terrain_generation.md) is the newest. Source line numbers and remarks about "the current port" describe the code at the time, not the editor today.

Use them as leads. Before relying on an address, formula, or claim, check it against the game binary, Pafta's code, or a side-by-side comparison with the game.
